## Reproducing the comparison

`uv run python -m locrag.study.selective_router summarize` rebuilds the numerical report offline. It checks the recorded source and examples against each rendered prompt, verifies each translation request hash, and confirms that every abstention produced the identical zero-shot text. The frozen [panel](panel.jsonl) contains the bilingual examples, routing decisions and both messages for every arm.

To regenerate the panel, restore the v2 TMs and candidate file as described in the [v2 reproduction guide](../../docs/v2-reproduction.md), then run `uv run python -m locrag.study.selective_router prepare`. The file is sufficient for the paid stage, `uv run python -m locrag.study.selective_router run`. Preserve the local ledger to reuse completed requests. Routes replay BGE-M3 retrieval against the historical TM snapshot; new embeddings are unnecessary. Accuracy and consistency use the same judge instructions and convention decisions as the [prior study](../consistency/protocol.md).
